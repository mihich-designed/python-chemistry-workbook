# Информационные технологии в химии — материалы занятий

Учебный репозиторий по Python, численным методам, оптимизации и анализу экспериментальных данных. Материалы подготовлены для занятий и разбора экзаменационных билетов.

## Структура проекта

```text
.
├── README.md
├── pyproject.toml              # зависимости и настройки uv
├── uv.lock                     # зафиксированные версии зависимостей
├── docs/                       # конспекты и теория по темам
│   └── optimization/
│       └── level_curves.md     # линии уровня и выбор диапазона графика
└── src/                        # исполняемые примеры Python
    ├── optimization/           # минимум функции, линии уровня, SciPy
    └── regression/             # регрессия и оценка качества моделей
```

Пути внутри `src/` — рекомендуемая структура. Названия модулей можно выбирать по теме занятия или номеру билета.

## Запуск с uv

Установить [uv](https://docs.astral.sh/uv/), затем из корня проекта:

```powershell
uv sync
```

Запуск примера (если файл сохранён по указанному пути):

```powershell
uv run python src/optimization/ticket_11.py
```

Добавление зависимостей в новый проект (если они ещё не указаны в `pyproject.toml`):

```powershell
uv add numpy scipy matplotlib
```

Все команды запускаются из корневой папки репозитория. `uv sync` устанавливает зависимости из `pyproject.toml` и `uv.lock` в окружение проекта.

## Изучаемые темы

| Тема | Разобрано | Следующий шаг |
|---|---|---|
| `objective(point)` | Целевая функция принимает координаты и возвращает значение | Самостоятельно писать функции для новых задач |
| `scipy.optimize.minimize` | Назначение минимума, стартовая точка, `result.x`, `result.fun`, `result.success` | Влияние стартовой точки, проверки, методы оптимизации |
| `np.linspace`, `np.meshgrid` | Создание массивов координат и двумерной сетки | Уверенно выбирать область графика |
| NumPy и векторизация | Одна `objective` работает с числами и массивами | Закрепить вычисления поэлементно |
| Линии уровня | Смысл уровней `0.1`, `0.5`, `1.0`, `1.5` | Подробно освоить `contour()` и оформление графиков |
| 3D-поверхность | Различие X/Y (координаты) и Z (значение функции) | `plot_surface()`, связь с 2D-картой уровней |
| Регрессия | Обсуждали назначение модели и МНК | Практический разбор остатков, MAE, RMSE, R² |

**Текущий фокус:** экзаменационный билет № 11 — квадратичная функция двух переменных, построение линий уровня и поиск минимума; затем линейная регрессия.

## Принцип организации

- В `docs/` — определения, формулы, объяснения и заметки к занятиям.
- В `src/` — рабочие Python-модули с решениями, желательно по одной теме на модуль.
- Конспект ссылается на соответствующий код, а код остаётся запускаемым отдельно.

> Статус тем отражает текущий прогресс обсуждения, а не факт полного освоения всех перечисленных навыков ученицей.
