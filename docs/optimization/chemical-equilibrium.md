## Шаг 1. Какую задачу решаем?

Реакция образования аммиака:

$$N_2 + 3H_2 \rightleftarrows 2NH_3$$

Знаем начальные концентрации азота и водорода. Ищем **равновесные концентрации** оставшихся N₂, H₂ и образовавшегося NH₃.

- `C_N2` — концентрация **молекул N₂**, моль/л.
- `C_H2` — концентрация **молекул H₂**, моль/л.
- `C_NH3` — концентрация **молекул NH₃**, моль/л.
- `_0` в обозначении — **начальное состояние**.

> [!WARNING]
> **Термины**  
> `C_N2 = 2.0` означает **2 моль молекул N₂ на литр**, а не 2 атома азота. `C_H2**3` и `C_NH3**2` в выражении равновесия — **математические степени концентраций**, а не количество молекул.

## Шаг 2. Исходные данные

```python
k = 0.25
C_N2_0 = 2.0   # Начальная концентрация молекул N2, моль/л
C_H2_0 = 6.0   # Начальная концентрация молекул H2, моль/л
C_NH3_0 = 0.0  # Аммиака изначально нет, моль/л
```

`k` — заданная константа равновесия **учебной модели** при рассматриваемых условиях.

## Шаг 3. Как вычисляем концентрацию аммиака?

Задано выражение равновесия:

$$k = \frac{C_{NH_3}^{2}}{C_{N_2}\cdot C_{H_2}^{3}}$$

Выразим концентрацию аммиака:

$$C_{NH_3}=\sqrt{k\cdot C_{N_2}\cdot C_{H_2}^{3}}$$

```python
C_NH3 = (k * C_N2 * C_H2**3)**0.5
```

**Идея:** оптимизатору достаточно подбирать `C_N2` и `C_H2`, а `C_NH3` мы вычисляем из них.

## Шаг 4. Балансы атомов — почему множители именно такие?

В реакции атомы азота и водорода сохраняются, но оказываются в разных молекулах.

**Баланс азота:**

$$2C_{N_2}+C_{NH_3}=2C_{N_2,0}$$

- В одной молекуле N₂ **2 атома N** → `2 * C_N2`.
- В одной молекуле NH₃ **1 атом N** → `C_NH3`.
- Изначально атомы азота были в N₂ → `2 * C_N2_0`.

**Баланс водорода:**

$$2C_{H_2}+3C_{NH_3}=2C_{H_2,0}$$

- В H₂ **2 атома H**, в NH₃ **3 атома H**.

> [!TIP]
> **Простой пример**  
> Было `C_N2_0 = 2`, стало `C_N2 = 1`: прореагировал 1 моль/л N₂ и образовалось 2 моль/л NH₃. Баланс азота: `2 * 1 + 2 = 2 * 2`, то есть `4 = 4`.
>
> **Не умножаем `C_NH3` ещё раз на 2** из уравнения реакции: концентрация NH₃ **уже содержит всё образовавшееся количество молекул**. Множители в балансе означают число атомов соответствующего элемента **в одной молекуле**.

## Шаг 5. Что такое невязка?

**Невязка** — разница между правой и левой сторонами баланса, приведённая к одной стороне. Чем она ближе к нулю, тем лучше соблюдается баланс.

$$F_1=2C_{N_2}+C_{NH_3}-2C_{N_2,0}$$

$$F_2=2C_{H_2}+3C_{NH_3}-2C_{H_2,0}$$

Чтобы одновременно уменьшить обе невязки, создаём **целевую функцию**:

$$F=F_1^2+F_2^2$$

Квадраты нужны, чтобы положительные и отрицательные отклонения не компенсировались. Идеальное значение `F` — 0.

## Шаг 6. Пишем `objective(point)`

```python
def objective(point):
    # Пробные равновесные концентрации, которые подбирает minimize
    C_N2 = point[0]
    C_H2 = point[1]

    # Концентрация аммиака из выражения константы равновесия
    C_NH3 = (k * C_N2 * C_H2**3)**0.5

    # Невязки по балансу атомов N и H
    F1 = 2 * C_N2 + C_NH3 - 2 * C_N2_0
    F2 = 2 * C_H2 + 3 * C_NH3 - 2 * C_H2_0

    # Одно число: суммарная квадратичная невязка
    return F1**2 + F2**2
```

`objective([0.5, 0.5])` **не сообщает готовый ответ**. Мы лишь проверяем пробные концентрации. Оптимизатор многократно вызывает функцию с разными аргументами.

## Шаг 7. Вызываем `minimize()`

```python
from scipy.optimize import minimize

result = minimize(
    objective,                 # Что минимизируем
    [0.5, 0.5],                # Стартовая пробная точка
    bounds=[(0, C_N2_0),       # Остаток N2 от 0 до исходного
            (0, C_H2_0)]       # Остаток H2 от 0 до исходного
)
```

- `objective` передаём без скобок, чтобы SciPy сам вызывал функцию.
- `[0.5, 0.5]` — начальные предположения, не результат.
- `bounds` запрещает отрицательные концентрации и ограничивает их исходными значениями, так как **аммиака вначале не было**.
- `result.x` — найденные `C_N2`, `C_H2`.
- `result.fun` — **сумма квадратов невязок**, не концентрация и не константа равновесия.
- `result.success` — статус завершения алгоритма.

## Шаг 8. Обрабатываем найденный результат

```python
C_N2 = result.x[0]
C_H2 = result.x[1]
C_NH3 = (k * C_N2 * C_H2**3)**0.5

print("Успешно:", result.success)
print("Сумма квадратов невязок:", result.fun)
print(f"C_N2 = {C_N2:.4f} моль/л")
print(f"C_H2 = {C_H2:.4f} моль/л")
print(f"C_NH3 = {C_NH3:.4f} моль/л")

F1 = 2 * C_N2 + C_NH3 - 2 * C_N2_0
F2 = 2 * C_H2 + 3 * C_NH3 - 2 * C_H2_0
print(f"Невязка азота: {F1:.8f}")
print(f"Невязка водорода: {F2:.8f}")
```

Приблизительный ожидаемый результат:

| Что нашли | Значение |
|---|---:|
| `C_N2` | 0.9142 моль/л |
| `C_H2` | 2.7427 моль/л |
| `C_NH3` | 2.1715 моль/л |
| `result.fun` | Практически 0 |

> [!IMPORTANT]
> **Проверка**  
> Если обе невязки практически равны нулю, балансы выполняются. `success=True` означает успешное **численное завершение**, но не заменяет проверку корректности химической модели.

## Шаг 9. Полный запускаемый код

```python
from scipy.optimize import minimize

k = 0.25
C_N2_0 = 2.0
C_H2_0 = 6.0


def objective(point):
    C_N2 = point[0]
    C_H2 = point[1]
    C_NH3 = (k * C_N2 * C_H2**3)**0.5

    F1 = 2 * C_N2 + C_NH3 - 2 * C_N2_0
    F2 = 2 * C_H2 + 3 * C_NH3 - 2 * C_H2_0
    return F1**2 + F2**2


result = minimize(
    objective,
    [0.5, 0.5],
    bounds=[(0, C_N2_0), (0, C_H2_0)]
)

C_N2 = result.x[0]
C_H2 = result.x[1]
C_NH3 = (k * C_N2 * C_H2**3)**0.5

print("Успешно:", result.success)
print(f"Минимум невязки: {result.fun:.10f}")
print(f"Азот N2: {C_N2:.4f} моль/л")
print(f"Водород H2: {C_H2:.4f} моль/л")
print(f"Аммиак NH3: {C_NH3:.4f} моль/л")
```

## Итог

1. Задаём начальные концентрации и `k`.
2. Из предполагаемых `C_N2` и `C_H2` рассчитываем `C_NH3`.
3. Считаем невязки атомных балансов.
4. Возвращаем сумму квадратов невязок из `objective`.
5. `minimize()` подбирает концентрации, минимизирующие её.
6. Из `result.x` получаем концентрации, из `result.fun` — величину невязки.
